FIVE FRIENDS: HORDE 43-48 — QUEST STARTER CHECKS — v1.1.0
Reviewed 18 November 2026

HOW TO USE
Check only when already passing. Continue immediately if the target or usable object is absent.
New optional opportunities contribute zero XP and zero kills to the required route forecast.
Enemy pins are observed check areas, not promises of a fixed or available spawn.
Only use a starter or make its reward visit when that character actually has the item or active quest.
All newly added guide goals are note goals: they never hold a step.
Native pin format is /mappin <UiMapID> <x> <y>, with spaces and percent coordinates.

These notes are embedded beside the listed existing Polestar steps.
Run one /mappin command at a time. An enemy pin is a check area, not a guaranteed spawn.
